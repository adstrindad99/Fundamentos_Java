Repositório de estudos sobre os fundamentos da línguagem, reunindo exercícios e exemplos praticados em diferentes cursos.

Estrutura:
```
src/
├── dio/
│   └── logicadeprogramacao/
```

## Conteúdo por curso:

DIO — Formação Java Básico

    Abordagem de entrada de dados via Scanner, declaração e tipagem de variáveis, e formatação de saída de dados.

DevDojo Academy — Lógica de Programação

    Declaração e reaproveitamento de variáveis, concatenação de strings, operadores aritméticos e saída de dados.

Sobre a organização:

    Este repositório agrupa código por conceito, não por curso. Isso significa que o mesmo tópico ensinado em cursos
    diferentes é reunido aqui, evitando duplicação de repositórios para o mesmo assunto.
    O histórico de commits preserva a evolução do código conforme os pacotes foram reorganizados.
